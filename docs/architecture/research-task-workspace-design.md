# 研究任务工作台

2026-10-16：用户要求根据已讨论技术路线开始开发大功能。本次落地首项“研究任务工作台”：模型提出有限计划，服务端校验执行，用户可补充约束后继续。外部 MCP、独立审查角色与外部行动交付仍是后续功能，不在本模块中隐式开放。

## 用户闭环

用户选择一个知识库的 1–5 份已处理文档，输入研究目标。后台规划器返回最多 4 个检索步骤，或最多 3 个必要澄清问题。用户可查看计划后开始执行；需要澄清时补充信息，再规划。工作台展示每个步骤状态、引用片段、最终研究结果及运行记录。

任务可暂停、恢复和取消；刷新页面不丢失状态。暂停保留已落库步骤，恢复仅执行尚未完成步骤。用户补充新约束会产生新一轮计划，旧轮次检查点与结果保留在历史中，禁止将旧结论作为新证据。任务上下文与回答偏好、聊天历史隔离。

## 执行边界

- 新独立 `taskworkspace` 模块，归属知识研究，不修改现有三类聊天路由。复用限定文档检索，不扩展现有升级研究工具允许列表。
- 模型仅输出强类型计划：`SEARCH_DOCUMENTS` 步骤、查询词、选定文档 ID；不输出可执行代码、URL 或 SQL。服务端整份校验后才允许执行。综合作为应用固定最终步骤。
- 正常一轮 1 次规划、1 次综合；失败或暂停后的用户主动恢复可重新尝试尚未完成的阶段，每轮包含中断／失败调用合计最多 10 次模型请求，无隐藏重试；最多 4 步，每步最多 5 份文档、每份 topK=3。最终证据最多 16 条、12000 字符，输入最多 30000 字符，最终正文最多 4000 字符。每次激活执行最长 180 秒；每轮累计激活最多 5 次，任务最多 5 轮。预算是初始限制，不是性能承诺。
- 无证据时确定性返回资料不足，不调用综合模型；输出引用必须属于本轮证据且至少有一个有效引用，不把编号校验当作语义支持率。
- 1 个后台工作线程、2 个排队位置。模型与检索调用均由有界调用池隔离，超时后不允许迟到结果覆盖任务；不宣称供应商停止计费。
- 知识库及文档归属、处理状态、Embedding profile、内容哈希和索引时间在计划和执行前核验。来源变化要求用户重新发起新轮次，不使用旧检查点继续综合。
- 任务仅使用服务器 LOCAL_OWNER；客户端不能指定 owner。任务变更使用 revision 乐观并发校验；创建请求使用 clientRequestId 幂等。
- 取消和暂停立即持久化，执行令牌作废，迟到结果丢弃。进程重启后活动任务收敛为 PAUSED，用户主动恢复，不自动重放付费调用。
- 不执行业务副作用，不自动保存升级报告，不注入偏好，不添加登录或任意外部工具。

## 数据与接口

Flyway 新建 `research_task`，保存归属、知识库、创建幂等键、原始请求哈希、状态、revision、execution_id、当前轮次 JSON 检查点、时间与逻辑删除标记。`research_task_event` 保存每次变更的状态与检查点快照（用户可见的计划／执行数据，不包含隐藏思维链），同事务递增 revision；历史返回最多 100 条并标记是否截断。内容只经 API 给当前主体查看，普通日志不打印目标、约束或文档片段。

`/api/research-tasks`：GET 列表，POST 创建；`/{id}` GET 详情、DELETE 逻辑删除；`/{id}/commands` POST 强类型命令 `START/PAUSE/RESUME/CANCEL/SUPPLEMENT`，含 expectedRevision，SUPPLEMENT 含用户补充文本；`/{id}/events` GET 历史。列表分页。前端 `/research-tasks` 轮询有界快照，卸载或终态停止轮询；数据库是恢复依据。

状态：PLANNING → READY / WAITING_INPUT；READY → RUNNING；RUNNING → COMPLETED / INSUFFICIENT_EVIDENCE；活动态可进入 PAUSED / CANCELLED / FAILED。PAUSED / FAILED 通过显式 RESUME 回到原阶段；SUPPLEMENT 在非活动态开始新轮次。COMPLETED / INSUFFICIENT_EVIDENCE 可通过 SUPPLEMENT 继续研究；CANCELLED 不恢复。删除只允许非活动态。

## 验证与交付

必要工程门禁：计划结构和文档范围校验；创建重放和 revision 冲突；暂停／取消阻止迟到写入；检查点恢复；补充新轮次保留历史；来源变更；真实 PostgreSQL 持久化、重启恢复与逻辑删除；控制器参数验证；前端构建与代表页面流程。真实模型使用公开资料，分别记录流程结果与人工质量观察，不覆盖已有升级研究验收结论。

当前状态：后端、迁移、模型计划与综合、工作台页面已实现；工程、真实模型调试与页面验证见[验证记录](../evaluation/research-task-workspace-verification.md)。这是首版能力交付，独立语义评测与检索、成本优化列入整体架构形成后的集中完善，不宣称通用任务成功率。
