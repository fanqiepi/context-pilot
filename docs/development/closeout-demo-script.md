# 研序｜技术研究 Agent 展示录制脚本

状态：脚本已准备；只有实际视频文件及回看记录存在时才能标记录屏完成。人工语义复核按用户 2026-10-19 指示暂缓。

## 录制内容（约 3–5 分钟）

1. 开场展示“研序｜技术研究 Agent”：单用户、本机或可信网络；知识问答、确认动作、比对和偏好为已验收基线；升级研究默认关闭且质量验收未通过。
2. 在专用公开演示知识库展示两份 Markdown 文档及处理完成状态。不要展示私人库、凭据配置、浏览器供应商账户页或终端环境变量。
3. 在 `/chat` 提问公开资料中的事实，展开引用，指出引用支持的句子；再问资料中没有的保证，展示真实拒答或必要缺口。录制失败也保留，不拼接成全部成功。
4. 展示经确认动作的提案卡与独立确认入口。口述“模型只能提议；确认是独立请求”。不要用模型口吻替用户确认。
5. 在 `/research-tasks` 展示公开研究计划、执行轨迹与来源，刷新后展示持久化结果；如使用历史运行，明确标注历史回放。
6. 在 `/upgrade-research` 展示默认关闭提示，并打开本次独立验收报告，说明原始失败、TEST 不回用于调参、尚无人工质量分数。

## 完成登记

- 视频路径、文件 SHA-256、时长、录制日期：待实际录制后填写。
- 环境／代码：记录当前提交及未提交文件指纹；开发模式页面不冒称发布构建。
- 演示数据：只用 `evals/` 中公开合成资料；真实生成明确 DeepSeek/DashScope，离线模式明确不代表模型质量。
- 回看：核对字迹可读、没有密钥或私人信息、录制范围与声称一致。没有回看不得写已验证。
- 录屏仅为展示材料，不补足语义评分、真实 GitHub 16 次运行或干净机器安装门禁。
