## 当前还缺什么

生产 `ReadingAiConfiguration` 继续拒绝真实调用。已有费用账本测试不是供应商协议/计价证明。真实模型与 embedding 调用为零，付费授权仍为零。

1. 阅读专用供应商适配及独立本地 HTTP 协议测试：有效输出限制、无重试、实际请求/批次数、超时、取消、截断与 usage。现有 DeepSeek 选择不变。
2. 官方价格版本、可审计的上界估算及确定批次/索引清单；上述材料齐备后才可请求独立付费授权。
3. 获授权的真实采集、人工语义复核、真实读者试用、浏览器冷/热性能采样和新录屏。缺失项目不能拿工程替身或单次页面观察填充。

后续仍是同一“验证续读体验并准备展示”能力的收尾，不默认新增产品功能、不恢复旧研究调优、不把没有付费授权当成阻止一切离线协议开发的理由。不得用 TEST 调 Prompt；变更已冻结实现或资产须新版本，保留旧输入和失败。
