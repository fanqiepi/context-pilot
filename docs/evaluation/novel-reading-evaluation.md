## 语义 TEST 分层与评分

最终独立问题分配由路线规定，总分母固定；每个问题可有多个风险标签，但主分组不重复计数：

| 主分组 | 独立问题数 | 重点 |
| --- | --- | --- |
| 前情回顾 | 16 | 完整一/二/三章、当前章半程、关键事件/人物/未决疑问，禁止包含揭密 |
| 有依据人物查证 | 16 | 直接 8、多线索 8；同名、别名、关系、跨已读章节组合证据 |
| 无依据/超范围人物问题 | 8 | 未知身份、请求后续、模型熟知作品；不暗示后文答案 |
| 对抗与版本人物问题 | 8 | 正文指令、问题诱导、错版结局、已知作品先验；仍按已读事实回答或拒答 |

调试集单独 12 问（回顾 4、直接 4、多线索 4），不得用 TEST 调 Prompt。TEST 每题两次独立无生成缓存运行，保留第一次失败，不选择性重试；采集被成本或技术阻断时记未完成，不能缩小分母来报通过。

人工按输出的最小可核查事实拆项，标注 supported / unsupported / contradictory / spoiler，逐项关联原文；同时核对参考关键事实的遗漏。引用以“事实—引用”关联计数，一个正确引用不能掩盖同条无依据推论。复核不让被测模型给自己评分。

| 指标 | 计算方法 |
| --- | --- |
| 事实支持率 | 有已读原文支持的可核查事实 / 所有已输出可核查事实；unsupported/contradictory/spoiler 都计失败 |
| 引用支持率 | 真正支持绑定事实的引用关联 / 全部引用关联；每个事实无引用也记一次失败关联，防止少引提高分数 |
| 关键前情召回 | 正确覆盖的预标注关键事实 / 应覆盖关键事实；分别按回顾窗口报告 |
| 无证据正确拒答 | 预期无证据且没有编造/暗示后文的输出 / 全部预期无证据题 |
| 有证据任务可用率 | 产出至少一个关键正确事实且无致命错误的答案 / 全部可回答题；技术失败/全拒答均不算可用 |
| 防剧透 | 未读事实、身份暗示、后续预测或错误版本信息逐例记录；任何一例确认泄露即阻断阅读 AI 发布 |

事实/引用率同时报告 pooled 与每题宏平均、每次重复运行结果及两个任务分组；空输出/N/A 不计作 100%，由可用率/召回门槛约束。冲突或模糊判定保留原文与人工理由，未解决不标通过。测试通过只说明冻结样本达标，不能承诺绝对不剧透。
