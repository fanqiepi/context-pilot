## 修复

- 所有经过任务停止入口的失败/失效/恢复暂停状态在提交后记录 WARN `READING_WORK_STOPPED`，含 workId、traceId、type、status、code、固定类别 reason 和 retry=false。不打印异常堆栈、供应商响应体、问题、原文或密钥；事务回滚不宣称已停止。
- 生成结束状态区分 GENERATION_LENGTH、GENERATION_CONTENT_FILTER、GENERATION_FINISH_REASON，生成 token 上限、空响应和大小也各有类别。答案格式/字数/引用校验保留既有类别；协议 JSON、Content-Type、UTF-8、响应大小等有独立类别。其余失败仍有公共错误码兜底日志。
- `payload_json.failureReason` 持久化安全类别；可见任务视图暴露 failureReason，页面显示具体原因。范围外视图不暴露诊断或 usage，恢复时清理旧诊断。
- `reading_ai_call.usage_json.finishReason` 保存白名单化结束状态，未知供应商字符串归为 other，缺失响应保留 null。历史记录不回填猜测。无需新迁移，无原始输出留存。
- 公共 OUTPUT_INVALID 码、严格结果校验、调用上限、停止账本及零自动重试保持不变；不绕过供应商过滤、不放宽限制来生成成功状态。
