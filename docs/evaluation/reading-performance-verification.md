## 使用方式与口径

Docker、JDK 21、Node 22 和 frontend/node_modules 就绪后，从仓库根目录运行：

```powershell
.\tools\reading-performance.ps1 -Port 5214
```

脚本构建生产前端，启动一次性 Testcontainers 数据库和随机 loopback 后端。进入打印的 `/books` 地址；右下角显示完成时间。分别在 1280×900、390×844 视口执行至少 30 次“继续阅读→计时完成→书架→计时完成”。测量时保持页面可见；脚本不自动操作浏览器。第一次从未访问过的端口进入，记录静态资源实际传输；同源重新打开可观察浏览器缓存。不要将新端口解释为清空操作系统缓存。

终端提供完成信号命令，Ctrl+C 也会触发收尾。日志、fixture.json、browser-samples.jsonl、report.json 与 final-state.json 保存在唯一的 `backend/target/reading-performance-*` 目录。结束时关闭脚本创建的 Node 服务，测试检查读界和无 AI 任务后回收数据库。不要同时运行其他 Maven 测试或覆盖 frontend/dist。输出目录不能复用覆盖采样。

探针仅由独立服务注入，不写入生产构建。服务仅监听 127.0.0.1，采样写入校验同源；只允许阅读 GET 和本次样本版本的位置 PUT，不提供索引、任务、笔记确认或读界修改。后端真实 AI 关闭，旧付费数据库和账本不参与。

从原始报告重新计算（不发请求、不修改报告）：

```powershell
node evals/tools/reading-performance.mjs report evals/reports/reading-performance-v1/report.json
node --test evals/tools/reading-performance.test.mjs
```

浏览器计时起点为整页导航开始或点击链接；终点为控件存在、恢复提示出现、加载遮罩消失之后的两个动画帧。包括 loopback HTTP、脚本、DOM 和布局等待，不包括代理工具往返时间，也不是硬件级屏幕呈现测量。失败、隐藏、超时、溢出、错误位置、超量正文及超限样本全部保留。`BROWSER_SAMPLES_PASS` 只表示本组离线页面采样通过，不是整体验收。

## 固定样本与实测

Windows 11、AMD Ryzen 7 5800H、8 核/16 线程、34,221,649,920 bytes 内存；JDK 21.0.3、Node 22.12.0、PostgreSQL 17.10 / pgvector、IAB Chromium 155。使用未压缩的生产静态资源，本机网络，不模拟移动设备 CPU/网络。应用/数据库进程已经启动，未清空 OS/数据库缓存。

500 万正文 code points、1000 章、10000 段，每段带唯一序号；最后一章 400 段、20 万字，强制验证 20000 字符分页。初始恢复第 9610 段 offset=7，已读边界 0。自生成容量夹具不是语义语料，不属于正式 TEST。

| 流程 | 样本数 | 实测 | 结论 |
| --- | --- | --- | --- |
| 注册、存文件、解析预览 | 1 | 1188 ms | 热进程中的新导入，低于路线 120 秒门槛 |
| 确认导入 | 1 | 2015 ms | 低于 120 秒门槛 |
| 后续正文页服务调用 | 30 | p95 13.78 ms | 低于 500 ms；不含 HTTP/浏览器 |
| 位置保存服务调用 | 30 | p95 12.19 ms | 低于 500 ms；每次回读 offset=7、读界 0 |
| 桌面首次书架导航 | 1 | 718.6 ms | 新端口，静态资源 transferBytes>0；低于 2 秒 |
| 桌面点击续读 | 30 | p95 438.1 ms，最大 538.5 ms | 包含首次阅读器模块下载；后续复用模块 |
| 桌面返回书架 | 30 | p95 62.4 ms | 低于 2 秒 |
| 窄屏点击续读 | 31 | p95 327.5 ms，最大 362.8 ms | 30 次循环及一次缓存刷新后复核，均保留 |
| 窄屏返回书架 | 30 | p95 55.0 ms | 低于 2 秒 |
| 窄屏缓存后重新打开书架 | 1 | 178.7 ms | 静态资源 transferBytes=0、bodyBytes>0；API 仍请求 |

所有 61 次续读均加载 40 段，从第 9610 段恢复，读界 0，无横向溢出或页面错误。单次正文响应约 72 KB，没有下载整本书。采样后另行核对长章分页：DOM 从 40 段增至 80 段，9610–9689 连续无重复。滚动到分页按钮后自动保存第 9649 段 offset=0，服务端 resumeRevision=32、readBoundary=0、scopeRevision=0。目录显示版本 1000 章及第 20 页，未读标题隐藏；该交互不计作初始位置性能采样。

## 证据与检查

原始数据见[来源清单](../../evals/reports/reading-performance-v1/evidence.json)。report.json 保留环境、实现锁 SHA、资源计时和逐次样本；browser-samples.jsonl 为采集时追加写入的原始行；verified-summary.json 由最终工具重新计算，增加错位/分页/读界判定，未重跑或删除原始样本。final-state.json 为结束前服务端状态；pagination.json 与截图来自实际浏览器。

首次采集保留在 initial/：123 次页面计时中 68 次缺少资源条目，原因是浏览器默认资源计时缓冲区填满；页面耗时与位置观测仍保留，但该轮不能作为完整采集通过证据。最终工具在每次导航前清理已保存的条目，并设置有界缓冲区；完整重采后 123 次均有阅读 API 资源条目。initial/verified-summary.json 按最终规则重新计算为 INCOMPLETE_OR_FAILED，不覆盖旧原始报告中的初版结论。上表只采用修正后的最终采集，不挑选两轮中更快的数值。

- 前端 `npm run build`（包含 vue-tsc）通过；现有主包超过 500 kB 提示保留，未为达标结果进行无依据的打包重构。
- `ReadingPerformanceFixtureTests` 显式执行 1 项，0 失败/错误/跳过；包含 30 次服务读写、结束时读界 0 和 reading_task 数为 0。总测试时间包含浏览器操作窗口，不当作接口时延。
- Node 工具 4 项通过：采样不足、失败保留、p95、错位/超量/读界、同源写入、禁用付费操作、不可覆盖输出。
- `reading-eval.mjs validate`：60 条/4 份语料通过，acceptance-v9 源码和资产 MATCH；历史锁与失败记录无改动。
- 文档链接、脚本解析、证据指纹和完整 diff 检查通过；进程正常结束、独立容器回收。
