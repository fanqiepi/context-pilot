## 修改

ReadingHttpAdvice 在写错误 JSON 前先识别失效连接和已提交响应：

- AsyncRequestNotUsableException 与 Spring 识别的客户端断连不再写响应体，仅记录不含异常正文的 DEBUG 元数据。
- 已提交的 SSE/HTTP 响应不替换状态、媒体类型或正文。流超时记 DEBUG，其他异常继续记安全的 WARN 类型/requestId，不掩盖真实服务异常。
- 首次响应尚未提交时，资源不存在/参数错误/内部失败继续返回原有 4xx/503 JSON 和 no-store。
- 不改变阅读任务状态、模型调用、结果持久化或范围校验。EventSource 断连不触发模型重跑。
