## 交付范围

书架新增“回顾后继续”，保留当前阅读版本，恢复正文位置并打开助手。助手分为前情回顾、人物查证和历史，首次打开/切换时选取当前历史页最新可见的对应任务；历史分页仍可查看更早记录。打开页面不会自动创建新任务。结果显示已读边界、覆盖说明与原文入口，笔记沿用不可变预览和独立确认。助手底部可直接返回正文。

阅读器增加当前章序号、上一章/下一章及定位到当前页的目录入口。跨第 50/51 章时仅读取相关目录页；正文继续按章/游标加载，不下载整本书。初始恢复期间禁用相邻章操作，避免初始化尚未完成时的点击丢失。跳章与来源预览不推进已读范围；“确认读完本章”仍需既有确认流程。

后端只增加安全章序号与派生 executionMode 响应，无表结构或生产依赖变更。真实关闭、固定评测和离线替身在界面明确区分。固定评测模式不提供自由任务创建；所有服务端范围、费用、批准、停止账本和请求匹配规则不变。

一键脚本 [reading-demo.ps1](../../tools/reading-demo.ps1) 启动一次性 Testcontainers 数据库、测试专用只读 AI 替身及前端生产构建。替身拒绝生成/向量请求，只读取固定任务、演示引用与笔记。三个自创样本分别用于桌面、窄屏和 52 章目录。日志与完成信号放在唯一 target 子目录，结束回收容器并关闭脚本创建的前端，不改日常数据库。复现方法见[演示脚本](../development/reading-demo.md)。

## 浏览器实测

Windows、本机 IAB；前端 Vite 生产构建，后端随机 loopback 端口，固定离线结果。桌面视口 1280×900，窄屏 390×844。操作由执行代理完成，不是独立真人试用。

| 流程 | 实际结果 |
| --- | --- |
| 书架→回顾 | 一次点击打开最近可见固定回顾，恢复第 2 段 offset=3，已读边界为 2 |
| 原文预览→关闭 | 显示 E1 的第 1 段原文，关闭后仍在原位；服务端 resumeRevision=1、offset=3、boundary=2 未变 |
| 编辑→预览→确认 | 桌面标题改为“接着读之前 · 渡口”；预览时笔记数为 0，确认后为 1，保留 E1、sourceTaskId 和 userEdited=true |
| 人物查证 | 切换后展示固定“林舟去了哪里？”结果及原文入口；未创建新模型调用 |
| 返回正文→下一章 | 桌面到第 2 章，第 4 段 offset=0 保存成功；已读边界仍为 2 |
| 跨目录页 | 52 章样本从第 50 章恢复，下一章到 51；打开目录显示第 2 页的 51/52，未读标题隐藏；上一章回到 50 |
| 窄屏完整流程 | 打开回顾、查看/关闭引用、编辑“窄屏续读记录”、预览并确认保存、人物查证与返回正文均可操作 |
| 范围回退 | 将窄屏样本边界清空到 0，任务历史仅显示超出范围；笔记 total=1，但标题、正文、来源均隐藏；续读仍为原第 2 段 offset=3 |
| 刷新→继续读 | 刷新保持边界 0 和服务端续读位置；返回正文后切到第 2 章，自动保存成功，边界仍为 0 |
