# 研究成果审查验证记录

日期：2026-10-19。范围依据[已批准合同](../architecture/research-result-review-design.md)。本记录区分工程门禁、真实模型流程与语义观察，不改变 V1–V5 已验收和升级影响研究待验收状态。

## 交付实现

- `researchreview` 专用模块、V27 迁移与工作台审查面板；不开启通用工具或多 Agent。
- 服务端构造不可变任务快照，父任务锁与主体校验、创建幂等、快照三次尝试上限、单任务活动审查限制。
- 确定性引用检查，一次独立模型请求、强类型结果校验、服务端总体判定；每次审查最多 12 条断言，不宣称覆盖所有断言。
- 1 个运行槽、2 个排队槽；独立有界调用池、90 秒运行硬截止、180 秒排队截止、取消和重启失败收敛，迟到结果不能写回。
- 历史、来源时效、usage 与 trace 持久化；来源变更后隐藏答案、证据与模型说明，父任务删除后不再允许读取。
- 用户编辑补充建议后通过现有 SUPPLEMENT 开启新轮次；审查不自动修改答案、检索、保存报告或提交业务动作。

## 工程证据与问题修复

专项测试为 `ReviewValidatorTests`、`ReviewModelGatewayTests` 和 `ReviewPersistenceTests`。真实 PostgreSQL 17/pgvector 由 Testcontainers 启动，迁移运行到 V27；覆盖幂等并发、跨主体/知识库、来源变化/删除、任务补充/删除、尝试上限、取消/迟到、排队拒绝、截止时间、重启与接口参数校验。模型网关测试验证独立上下文、禁用工具、超限时零调用；结构测试覆盖四类判断、伪造引用、空/非法/超限输出和断言原文定位。

首次专项执行有一个夹具错误：切换到外部主体时未先插入 `app_user`，触发外键；修正夹具后专项通过。首次全量回归发现工作台关闭时仍装配审查服务，导致无数据库应用上下文门禁失败；已经把服务和来源组件纳入同一工作台开关。第二次全量运行因开发服务重编译同一 `target/classes` 导致类文件暂时缺失，该运行不作为通过证据。最终结果必须来自停止并行编译后的串行构建。

前端 `npm run typecheck` 和 `npm run build` 通过；构建保留既有大 chunk 警告，不作性能提升声明。最终后端构建统计见下文。

## 真实模型与页面

冻结公开案例：[research-review-v1.json](../../evals/cases/research-review-v1.json)。初次八次调用均完成结构校验；逐项输入/输出和人工可复核说明见[原始结果](../../evals/results/research-review-2026-10-19/live-results.json)与[观察](../../evals/results/research-review-2026-10-19/observations.md)。四类主断言表现与预设证据一致，但部分结果提出目标外的假设性缺口，已登记为非阻断优化项。编码助手观察不是独立人工验收，不报告通用准确率。

页面通过本地真实后端、公开 `legacy-worker.md` 创建独立演示任务 `7678195b-3f45-463a-85e8-a1d066ca028f`。第一轮前两次审查失败，第二次脱敏日志确认 `ReadTimeoutException`；采用显式 JDK HTTP 传输配置（10 秒连接、90 秒读取）后第三次完成，应用硬截止仍为 90 秒，未新增重试。此前两次失败留在历史，没有重置尝试次数或删除失败记录。首次失败缺少根因日志，不能断言它与第二次完全同因。

页面已验证审查入口、执行状态、完成结果、展开证据、刷新恢复、补充后旧审查标记历史。窄面板截图见[审查页面](../../evals/results/research-review-2026-10-19/review-page.png)。第二轮审查、建议填入、用户编辑并提交、第三轮完成与历史隔离均通过真实页面操作核验，完整快照见[页面流程](../../evals/results/research-review-2026-10-19/page-flow.json)。点击填入建议时任务保持第 2 轮 COMPLETED，提交后才进入第 3 轮；第三轮最终 COMPLETED / revision 28。第二轮对 FIFO 释义的过于严格判断已纳入质量观察。

## 已知限制

本能力是首版固定审查步骤，不是独立事实核验系统。长答案覆盖、提示注入对语义判断的影响、误报/漏报及费用优化需要独立更大样本；结构验证与禁用工具只证明执行边界，不证明模型判断可信。默认工作台开关仍关闭，`LOCAL_OWNER` 不构成认证，部署范围仍限本机或可信网络。

## 最终工程结果

串行 `mvnw.cmd -q package` 退出码 0；94 个测试套件共 493 项，483 通过、10 条件跳过、0 失败、0 错误，生成可执行 jar。统计见[构建摘要](../../evals/results/research-review-2026-10-19/build-summary.json)。跳过项主要是需显式开启的真实模型测试，不计为通过；专项真实调用另外执行并记录。前端类型检查和生产构建通过，`git diff --check` 无空白错误。

结论：研究成果审查首版工程与代表用户闭环交付完成；独立语义质量评估、目标外建议收敛和误报/漏报优化仍需后续集中处理，不把本次结果标成通用研究质量验收。

最终专项复验：`mvnw.cmd -q -Dtest=Review*Tests -Dcontextpilot.evaluation.review-live=true test` 退出码 0，19 项全部通过（含 1 项内部执行八次真实调用的测试）。最终批原始输出见[最终模型结果](../../evals/results/research-review-2026-10-19/final-live-results.json)，实现文件哈希见[manifest](../../evals/results/research-review-2026-10-19/manifest.json)。最终批出现范围过审与 UNSUPPORTED/CONTRADICTED 混淆，属于明确保留的语义质量问题，不能据工程通过宣称审查质量验收。两批共 16 次调用，均只使用公开合成样本。
