# Echo Platform（合成评估资料）

## deployment
Echo 作为无服务器服务交付，用户只需配置区域和容量上限。

## limits
Echo 每个账户默认 20 个环境，单请求执行时间最长 90 秒。

## security
Echo 支持单点登录、环境隔离和每次部署的不可变审计记录。

## observability
Echo 提供实时日志、调用指标和采样追踪，默认保留 7 天。

## recovery
Echo 在三个可用区复制配置，服务目标为 RPO 五分钟、RTO 十五分钟。

## cost
Echo 按调用次数、执行时长和出口流量计费，没有固定节点费用。
